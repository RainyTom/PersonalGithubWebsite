## 给功能一个最小例子

假设要为博客按日期排序。先写下两篇文章的数据，再写出希望得到的顺序。此时可以很快发现问题：日期是字符串还是时间戳？没有日期怎么办？相同日期按什么排序？

## 让规则进入代码

统一为 YYYY-MM-DD 格式的日期字符串后，可以按字符串比较。若需要处理时刻或跨时区事件，就不能直接沿用这个简化。

```js
const posts = [
  { id: "b", date: "2026-01-02" },
  { id: "a", date: "2026-01-02" },
];
posts.sort((a, b) =>
  b.date.localeCompare(a.date) || a.id.localeCompare(b.id)
);
```

## 检查边界，而不是增加花样

接着考虑空列表、单篇文章和日期相同的情况。稳定的次级排序可以让重复构建结果一致，也能减少分页时文章跳动。

这个练习适用于很多小功能：先用具体数据约定结果，再决定是否需要抽象。
