# 你好，我是 Rainy Tom。

写一点代码，记录一些问题，也给日常留一点空白。

这个博客保存技术笔记、实践中的思考和偶尔的随笔。希望这些记录能帮助未来的自己，也让恰好遇到相同问题的人少走一点弯路。

## 关于这里

我喜欢清楚的解释、具体的例子，以及可以反复翻阅的记录。文章不需要封面，一段标题和摘要就足够成为阅读的入口。

代码可以复制，想法可以讨论。发现错误时，欢迎通过 [GitHub 仓库](https://github.com/RainyTom/PersonalGithubWebsite)提出建议。

## 内容来源

文章会注明来源：手写记录、本地主题库每日练习，或 AI 辅助生成。本地主题会循环；练习不代表亲身经历。AI 内容可能存在错误，使用其中的事实或命令前请核实。

## 保持联系

你可以通过网站页脚的 RSS 订阅更新，也可以在 GitHub 找到这个博客的完整源码。
